# 🌦️ Skylytics

Skylytics is an advanced weather application that delivers real-time atmospheric data with a modern and responsive interface.  
It provides hourly updates, detailed weather metrics, and a clean visual experience.

---

## Features

- Real-time weather updates  
- Hourly temperature and condition tracking  
- Rain probability percentage  
- Humidity and visibility readings  
- Interactive 24-hour weather chart  
- Automatic data refresh every 30 minutes  
- Simple and responsive UI  

---

## Tech Stack

- **Frontend:** Vue 3 (Composition API)  
- **API:** OpenWeatherMap  
- **Charting:** Chart.js  
- **Styling:** Tailwind CSS
